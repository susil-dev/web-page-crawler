# Classic (Non-AI-First) Web Scraper Extensions on the Chrome Web Store

Research date: 2026-11-25. Chrome Web Store (CWS) figures were read directly from the listing pages on that date unless noted otherwise. CWS rounds user counts (for example "100,000" means 100,000+), and the listings say "Ratings are updated daily and may not reflect the most recent reviews."

## Which extensions are most widely used, and what are their store metrics (users, rating, last update, Manifest version)?

### Takeaway
Instant Data Scraper (about 1M users, 4.9 stars from 7.8K ratings) and Web Scraper by webscraper.io (about 900K users, 4.7 stars from 1.1K ratings) are the two clear leaders. Next come Data Miner, now listed as "Data Scraper - Easy Web Scraping" (about 300K users, but only 3.6 stars), Table Capture (200K), Listly and Easy Scraper (100K each), Simplescraper (about 60K) and Agenty (10K). Every active extension in this group was updated between September and November 2026. The original "Scraper" extension by dvhtn appears to be dead or delisted.

### Inferences
- **Manifest version.** None of the listings state it. Because MV2 items were purged from CWS and all active extensions above (except dvhtn Scraper) received updates in late 2026, they are almost certainly MV3.
- **dvhtn Scraper.** Most likely delisted, or at least non-functional for new installs, because of the MV2 purge. It has had no visible updates since about 2015-2016. Treat it as abandoned.
- **Ratings versus popularity.** Data Miner's 3.6 rating stands out given its 300K users. It likely reflects frustration with the freemium page limits and domain restrictions (see pricing below), but I collected no review text to confirm this.
- **Easy Scraper.** A perfect 5.0 from 1.3K ratings is unusual. It may reflect a young listing or review solicitation. Treat it with caution.

### Gaps
- **Manifest version.** Not shown on any CWS page. Confirming it would mean inspecting each extension's manifest.json, for example from a CRX download.
- **dvhtn Scraper and successor.** I could not read the current listing state of the dvhtn Scraper or its claimed MV3 successor, because both pages loaded empty. Chrome-stats.com was unreachable.
- **Simplescraper.** I could not fetch the listing directly, so there is no exact last-updated date or version.
- **Other large-user-base extensions.** I did not survey others, such as Octoparse's or Bardeen's extensions, or the many "email extractor" scrapers.

## Pricing: free tier limits and paid plans

### Takeaway
There are three pricing models:
1. **Fully free, local-only:** Instant Data Scraper and Easy Scraper.
2. **Free local extension plus paid cloud:** Web Scraper and Simplescraper.
3. **Freemium extension with hard limits or paywalled export:** Data Miner (500 pages/month), Table Capture (250 rows; file downloads and multi-page capture are Pro), and Agenty (full export needs a paid plan).

Listly's store page advertises a free tool with guest mode and lists no paid tiers. Third-party reviews say its advanced features are paywalled.

### Cited Findings
**Web Scraper.** The extension is free for local scraping, including creating, running and exporting sitemaps, with no account needed. — [webscraper.io blog](https://webscraper.io/blog/web-scraper-vs-instant-data-scraper)

Web Scraper Cloud plans (prices billed annually, per month):

|---|---|---|---|---|
| Project | $50 | 5,000 | 2 | 30 days |

| Scale | from $200 | "unlimited" | priced per scraper ($100 each at 2, $90 each at 10) | 60 days |
| Enterprise | custom | custom | custom | custom |

- One credit equals one page load. There is a 7-day free trial with no card required.
- Every plan includes datacenter proxies (US, UK, DE). Residential proxies are a Scale add-on at $2.50/GB.

**Easy Scraper.** Described on its listing as "A free web scraper", with no paid tiers mentioned. — [CWS listing](https://chromewebstore.google.com/detail/easy-scraper-one-click-we/cljbfnedccphacfneigoegkiieckjndh)

**Table Capture:**

**Simplescraper.** Local scraping is free and unlimited. Cloud runs and API use consume credits, with 100 free cloud credits per month. — [ProfileSpider roundup](https://profilespider.com/blog/top-free-chrome-extensions-for-web-scraping-in-2025) (secondary, via search summary; the official pricing page did not render)

### Inferences
- **Two monetization styles.** Web Scraper and Simplescraper monetize cloud execution. Data Miner, Table Capture and Agenty monetize the extension itself (page quotas, row caps, export paywalls), which tends to generate negative reviews.
- **Price anchors for a new extension.** About $20/month buys roughly 500 pages (Data Miner Solo). About $50/month buys 5K cloud page loads (Web Scraper Project).

### Gaps
- Exact current prices for Simplescraper, Listly, Table Capture Pro/Cloud and Agenty. Their pricing pages did not render or list numbers.

## Features per extension (selection, pagination, crawling, dynamic content, login, scheduling, cloud, exports, recipes, cleanup, delays, images)

### Takeaway
- **Most powerful and complex:** Web Scraper. It uses a sitemap/selector-tree model with link following, pagination, click and scroll actions, and login state, plus a cloud tier for scheduling, API access and integrations.
- **Simplest:** Instant Data Scraper. It auto-detects the main list or table, then handles next-button pagination, infinite scroll and delays, with CSV/XLSX export only.
- **Middle tier:** Data Miner (recipe library), Agenty (auto-detect plus templates and cloud), Listly (lists, multi-tab, detail pages, Google Sheets) and Easy Scraper (one-click lists plus detail pages).
- **Table specialist:** Table Capture.

### Cited Findings
**Web Scraper (webscraper.io):**
- **Selector types:**
  - Data: Text, Image, Table, Element attribute, HTML.
  - Navigation: Link, Pagination, Sitemap.xml Link.
  - Structure and actions: Element (record wrapper), Element click, Click once.
  - Selectors form a parent/child tree that runs top to bottom. Each selector has a per-selector Delay for asynchronously updating pages.
  - Docs nav links to "Website State Setup / Sign-in", "Data export" and "Image export".
  - [Selector docs](https://webscraper.io/documentation/selectors)
- **Listing features:** multi-page scraping; text, image and URL extraction; dynamic JS/AJAX and infinite-scroll pages; browsing scraped data; CSV/XLSX download; optional full automation via Web Scraper Cloud. — [CWS listing](https://chromewebstore.google.com/detail/web-scraper-free-web-scra/jnhgnonknehpejjnehehllkliplmbmhn)
- **Selection workflow:** an "AI Sitemap Wizard" detects repeating content, and an "Advanced Sitemap Builder" allows manual selectors.
- **Crawling:** follows listing links to detail pages and attaches the detail fields to each parent record.
- **Login:** local runs use the user's logged-in browser session. Website State Setup can type text, click, or set location or currency.
- **Limitations:** a steeper learning curve, and local runs need the browser to stay open.
- [webscraper.io blog, 2026-08-19 (vendor-authored)](https://webscraper.io/blog/web-scraper-vs-instant-data-scraper)
- **Cloud features:**
  - API and scheduler (intervals and custom CRON).
  - No-code "Parser" for per-column transforms, i.e. data cleanup.
  - Data-quality monitoring with validation rules and email alerts.
  - Export to CSV, XLSX and JSON.
  - Integrations: Dropbox, Google Drive, Google Cloud, Google Sheets, Azure, S3, webhooks.
  - Proxies, log-in feature, image download, CAPTCHA and bot-protection bypass, automatic retries.
  - [webscraper.io pricing](https://webscraper.io/pricing)

**Instant Data Scraper:**
- AI-based (heuristic) detection of the data to extract.
- Detects when dynamic content has loaded, with a customizable delay and maximum wait time.
- Pagination via next-page buttons or links, plus infinite scroll.
- Data preview with copy and paste; column rename and filter; export to Excel or CSV.
- [CWS listing](https://chromewebstore.google.com/detail/instant-data-scraper/ofaokhiedipichpaobibbnahnkdoiiah)
- No detail-page link following, no scheduling and no cloud. Focused on repeated data on the current page. — [webscraper.io blog (vendor-authored)](https://webscraper.io/blog/web-scraper-vs-instant-data-scraper)

**Data Miner:**
- Automated crawling of paginated sites; single-page or multi-page scraping with crawl; automatic next-page navigation.
- Email extraction via regex; download of completed pages with images; UTF-8 support.
- Form filling from XLS files.
- Export to XLS, CSV, XLSX and TSV.
- Over 1 million user-generated extraction "recipes".
- [CWS listing](https://chromewebstore.google.com/detail/data-miner/nndknepjnldbdbepjfgmncbggmopgden)
- Paid plans add crawl automation ("Automate Scrape Crawls"), custom JavaScript and a Google Sheets connection. — [dataminer.io pricing](https://dataminer.io/pricing)
- A secondary source cites 60K+ community recipes, which conflicts with the listing's "1 million". The search summary also attributes to a third-party review the claim that Data Miner "cannot be used for complex web scraping tasks requiring data extraction from dynamic websites". — [ProWebScraper review](https://prowebscraper.com/blog/?p=2880) (via search summary)

**Agenty (extension):**
- **Selection:** auto-detects lists and tables, offers a point-and-click field picker, and accepts optional custom CSS selectors. Extracts text, links, images and attributes.
- **Specialized extraction:** emails (from text, mailto links and attributes); images, with a gallery preview and ZIP download.
- **Pagination:** auto-scroll, "Next" buttons, URL patterns and URL lists.
- **Templates and reuse:** templates for 50+ sites (100+ presets per the changelog); saved, re-runnable scrapers with run history.
- **Run controls:** adjustable speed, delays, timeouts, page limits and auto-scroll.
- **Export:** XLSX, CSV and JSON.
- **Cloud:** deploy to Agenty Cloud for scheduled runs with proxies, crawling and API access.
- [CWS listing](https://chromewebstore.google.com/detail/agenty-advanced-web-scrap/gpolcofcjjiooogejfbaamdgmgfehgff)

**Listly:**
- Click a list, table or card to capture all similar items.
- Auto-scroll and pagination.
- Extract all open tabs at once.
- Follow each link in a list to collect detail pages.
- Export to Excel or Google Sheets; guest mode.
- [CWS listing](https://chromewebstore.google.com/detail/listly-web-scraping/ihljmnfgkkmoikgkdkjejbkpdpbmcgeh)

**Easy Scraper:**
- One-click list scraping on any site; scrapes detail pages by visiting each URL in an extracted list.
- Handles JavaScript-rendered content.
- Processes data locally (nothing is sent over the network).
- Adjustable list selection and scraping speed.
- Export to CSV and JSON.
- [CWS listing](https://chromewebstore.google.com/detail/easy-scraper-one-click-we/cljbfnedccphacfneigoegkiieckjndh)

**Table Capture:**
- **Free:** copy tables to the clipboard; export to Google Sheets; batch export; capture div-based tables and other repeating items (up to 250 rows).
- **Pro:** Excel/CSV download, multi-page and scroll-loaded tables, Markdown, PNG, Office 365, per-site "Recipes", and PDF tables.
- **Cloud:** live Google Sheets sync and AI columns.
- [CWS listing](https://chromewebstore.google.com/detail/table-capture/iebpjdmgckacbodjpijphcplhebcmeop)

**Simplescraper.** A point-and-click tool, with free local scraping and paid cloud runs and API access. — [Oxylabs roundup](https://oxylabs.io/blog/best-web-scraping-chrome-extensions) (via search summary)
- Its promo banners on other CWS listings now position it as an "AI web scraper" with scheduled bulk scraping, an API and MCP. — [CWS search results](https://chromewebstore.google.com/detail/agenty-advanced-web-scrap/gpolcofcjjiooogejfbaamdgmgfehgff) (search summary)

## Common complaints and praise in reviews

### Takeaway
I could not fetch individual CWS reviews: the listing pages expose only aggregate ratings to the fetcher, and G2 blocked the fetch. Rating levels plus pricing structures point to these patterns:
- Free, unlimited tools score highest: Instant Data Scraper 4.9, Easy Scraper 5.0, Web Scraper 4.7, Listly 4.7.
- Quota or paywall tools score lower: Data Miner 3.6, Agenty 3.1, Table Capture 4.1.

### Cited Findings
- **Instant Data Scraper praise:** "a fantastic entry-level tool... free, easy to install, and can save you hours of manual work if your needs are simple". — [Thunderbit review (competitor)](https://thunderbit.com/blog/instant-data-scraper-review-and-alternative) (via search summary)
- **Instant Data Scraper weakness:** described as best suited to "easy, one-off list exports" rather than ongoing jobs. — [Apify blog (competitor)](https://blog.apify.com/top-instant-data-scrapers) (via search summary)
- **Web Scraper weaknesses:** a steeper learning curve, and local runs require the browser and computer to stay on. — [webscraper.io blog (vendor)](https://webscraper.io/blog/web-scraper-vs-instant-data-scraper)
- **Data Miner limits:** the free plan's 500 pages/month cap and domain restrictions are the main limitations, and accounts lock when the cap is exceeded. — [dataminer.io pricing](https://dataminer.io/pricing); [webscraper.io "Web Scraper vs Data Miner" (vendor)](https://webscraper.io/blog/web-scraper-vs-data-miner) (via search summary)
- **Agenty paywall:** scraping is free but exporting full results needs a paid plan, which plausibly explains its 3.1 rating. — [CWS listing](https://chromewebstore.google.com/detail/agenty-advanced-web-scrap/gpolcofcjjiooogejfbaamdgmgfehgff)
- **Table Capture caps:** the free tier is capped at 250 rows, and CSV/Excel downloads need Pro. — [CWS listing](https://chromewebstore.google.com/detail/table-capture/iebpjdmgckacbodjpijphcplhebcmeop)
- **Simplescraper reviews:** individual CWS reviews are mostly positive, with one calling it the best scraper the reviewer had tried. — [CWS reviews](https://chromewebstore.google.com/detail/lnddbhdmiciimpkbilgpklcglkdegdkg/reviews?hl=en) (via search summary)

### Inferences
- **Paywalls hurt ratings.** Users punish surprise paywalls at the export step (Agenty, Table Capture) and hard quotas (Data Miner) far more than limited feature sets (Instant Data Scraper). A free local core with optional paid cloud (Web Scraper) keeps ratings high.
- **Complaints I expect but could not confirm.** Generic complaint themes include auto-detection picking the wrong list, pagination stopping early, and breakage after site redesigns. I found no primary review text supporting them.

### Gaps
- Individual CWS review text, G2/Capterra scores and Reddit threads were not retrievable in this session. The G2 fetch failed on SSL, and searches returned only vendor or competitor blogs, most of which are biased because they come from competing scraper vendors.
